# Automatic harness evolution

- AHE: 구성요소 observability(파일 단위 표현, 되돌릴 수 있음), 경험 observability(수백만 토큰 trajectory를 계층적 증거로 요약), 의사결정 observability(편집마다 예측을 선언하고 다음 라운드 결과로 검증 = 반증 가능한 계약).
- NLAH: harness 정책을 자연어 문서로 두고 공유 런타임이 해석 -> 비교, 이식, ablation이 쉬워짐.
- Recursive Agent Harness: 부모 에이전트가 스크립트로 서브에이전트 harness를 병렬 생성.
